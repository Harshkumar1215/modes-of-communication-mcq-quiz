50 Questions | Simplex • Half-Duplex • Full-Duplex

📚 Core Summary Reference: Quick Refresher

1. Simplex Mode (A → B)

One-way only. One transmits, the other only receives. Examples: TV broadcast, keyboard to CPU, radio.

2. Half-Duplex Mode (A → B or B → A)

Two-way, taking turns. Both can transmit & receive, but NOT simultaneously. Example: Walkie-talkie.

3. Full-Duplex Mode (A ⇄ B)

Two-way, simultaneously. Both can transmit and receive at the exact same time. Example: Telephone, video call.
